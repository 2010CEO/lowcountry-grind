# Why home coffee gear

- **Commission:** Amazon pays **4.5% on Kitchen**, which covers almost all coffee gear. That's above Home, Outdoors, Sports, and Tools (3%). Grocery, which includes beans, pays only 1%, so the site sells *gear*, not coffee. (Amazon Associates fee schedule, checked 2026-11-20.)
- **Order size:** carts run from about $30 for a scale to $500+ for espresso machines and Moccamasters. "Best grinder / espresso machine for beginners" searches come from people about to buy.
- **Credibility:** a coffeehouse owner reviewing coffee gear is a real edge that generic affiliate sites can't fake. The Lowcountry angle (humidity, hard water, cold brew season, deer stand and boat coffee) gives the site a voice and long-tail keywords nobody else owns.
- **Timing:** coffee gear is a top holiday gift category, and the site launches 5 weeks before Christmas.
